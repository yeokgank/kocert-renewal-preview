(주)코서트는 KOLAS 공인시험기관(인정번호 KT1353)입니다. KS X ISO/IEC 25023 기능적합성과 ISO/IEC 25024 데이터 품질 항목은 코서트가 직접 시험해 공인시험성적서를 발급합니다. 정부 R&D 과제 결과 평가, 제품 품질 입증, 조달·입찰에 그대로 쓰이는 국가 공인 성적서입니다.

01정부 R&D 과제 결과 평가

02제품 품질 · 안전성 입증

기능적합성·데이터 품질을 국제표준 기준으로 측정한 수치로 제품 완성도를 객관화합니다.

03조달 · 입찰 제품 평가

입찰 제안서의 성능·기능 수치는 공인 성적서 첨부 시 인정됩니다.

04정보시스템 최종 검수

구축 사업 검수 조건으로 기능 시험 성적서가 들어가는 경우가 많습니다.

05홍보 · 마케팅

ILAC-MRA 상호인정으로 KOLAS 성적서는 해외 발주처에서도 통용됩니다.

시험 규격

두 가지 인정 규격으로 공인시험성적서를 발급합니다

코서트 KOLAS 인정 범위는 소프트웨어 분야 두 규격입니다. 범위 밖 항목(성능·보안·HW)은 코서트가 일반시험(V&V)으로 진행합니다.

소프트웨어 시험

KS X ISO/IEC 25023

KS X ISO/IEC 25023에 따라 기능적합성을 시험한 후 공인시험성적서를 발급합니다. 코서트는 KOLAS 공인시험기관으로서 공신력 있는 성적서를 직접 발급합니다.

KS X ISO/IEC 25023 개요

대상
공인시험이 필요한 모든 소프트웨어 (패키지 SW, 웹·모바일 서비스, 임베디드 SW)
목적
정부 R&D 과제의 결과 평가, 제품의 홍보 및 마케팅, 품질 평가, 제품의 품질과 안전성 입증
규격

시험 방법
국제표준 KS X ISO/IEC 25023을 기준으로 기능 명세와 실제 동작을 대조해 기능적합성을 측정합니다.

데이터 품질 시험

ISO/IEC 25024

기업 및 공공기관이 보유한 데이터를 국제표준 ISO/IEC 25024를 기준으로 객관적으로 시험해 데이터의 품질 완성도를 높이고, 양질의 데이터를 확보합니다. 코서트는 KOLAS 공인시험기관으로서 공인시험성적서를 직접 발급합니다.

ISO/IEC 25024 개요

목적
공급기관 — 사전 결함 탐지·수정으로 품질 완성도 제고, 거래·유통 데이터의 사전 품질 검증으로 분쟁 최소화와 고객 신뢰 확보, 가공·결합 융합 데이터의 품질 측정으로 데이터 가치 극대화
수요기관 — 사전 검증된 고품질 데이터 구매, 저품질 데이터로 인한 경제적 피해 예방
대상
데이터바우처 지원 사업으로 유통되는 데이터 · 마이데이터 · 공공/민간 데이터 · 빅데이터 거래 플랫폼 내 각종 데이터 · 고품질 가치 검증이 필요한 데이터 · AI 학습데이터 등 품질 검증이 필요한 데이터
규격
ISO/IEC 25024 데이터 품질 측정 (데이터 품질에 관한 국제표준)
시험 방법
국제표준 ISO/IEC 25024를 기준으로 데이터의 정확성, 완전성, 일관성, 현재성을 측정합니다.

시험 항목 (코서트 인정 범위)

ISO/IEC 25024 시험 항목과 방법
구분시험 항목시험 방법
정확성구문 데이터 정확성 (Acc-I-1)구문적으로 정확한 값을 갖는 데이터 아이템의 비율을 측정
데이터 범위 정확성 (Acc-I-7)지정된 범위 안에 포함된 데이터 아이템의 비율을 측정
완전성기록 완전성 (Com-I-1)완전성을 측정할 수 있는 레코드의 데이터 아이템 중 null이 없는 데이터 아이템의 비율을 측정
일관성참조 무결성 (Con-I-1)참조 관계가 정의된 데이터 아이템 중 참조 대상이 존재하는 데이터 아이템의 비율을 측정
현재성아이템 요청 업데이트 (Cur-I-2)업데이트 주기와 조건에 맞게 업데이트 요청이 있는 정보 아이템의 비율을 측정

※ 의미 데이터 정확성, 데이터 값 완전성, 준수성, 정밀성, 추적성, 이해성 등 인정 범위 밖의 항목은 코서트가 일반시험(V&V)으로 진행합니다.

※ 인정 범위는 KOLAS 인정서 별첨 기준(소재지 시험, 현장시험 미포함). 범위 밖 항목은 일반시험(V&V) 성적서로 발급됩니다.

전체 Q&A 보기
계획서 목표가 시험 가능한 형태가 아니면 어떻게 하나요?

가장 흔한 상황입니다. 목표의 의도를 유지한 채 측정 가능한 항목으로 재정의하고, 필요하면 과제 관리기관과의 변경 협의도 코서트가 함께 진행합니다.

성능이나 보안 항목도 코서트에서 발급하나요?

코서트 인정 범위는 기능적합성과 데이터 품질입니다. 성능·보안·HW 항목은 코서트가 일반시험(V&V)으로 시험해 성적서를 발급합니다. 공인 마크가 필요한 항목은 견적 단계에서 진행 방법을 안내해 드립니다.

성적서 발급까지 얼마나 걸리나요?

접수 후 2~3주가 기본이며 항목 수에 따라 달라집니다. 과제 종료 2개월 전에는 시작하는 것이 안전합니다.

비용은 어떻게 산정되나요?

시험 항목 수와 시료 규모에 따라 산정됩니다. 계획서를 주시면 항목 초안과 함께 견적을 드립니다.

일반시험과 무엇이 다른가요?

공인시험은 KOLAS 인정 범위 안의 규격 항목만 가능하고 국가 공인 효력이 있습니다. 의뢰자가 제시한 항목·방법으로 자유롭게 시험하려면 일반시험으로 진행합니다.
